# CI/CD

يعمل ملف `.github/workflows/ci.yml` على كل Pull Request وعلى الفروع الرئيسية، ويمكن تشغيله يدويًا.

يتحقق المسار من:

- بناء الخادم والواجهة الأمامية.
- فحص اعتماديات الإنتاج عبر `npm audit --omit=dev`.
- اختبارات منع الثغرات.
- اختبارات التكامل على PostgreSQL مع قاعدة اختبار معزولة.
- إنتاج حزمة إصدار موقعة بالـ commit وتخزينها كـ artifact لمدة 14 يومًا.

تستخدم الاختبارات `DATABASE_URL` خاصًا بقاعدة الاختبار ولا تقرأ `.env` المحلي. لا يوجد نشر تلقائي إلى الإنتاج في هذه المرحلة لأن بيئة الاستضافة وبيانات الاعتماد لم تُحدد بعد؛ وظيفة `package` تجهز حزمة قابلة للنشر، ويمكن ربطها لاحقًا بهدف نشر محدد بعد إضافة أسرار البيئة في GitHub.

يقوم Dependabot بفتح تحديثات أسبوعية منفصلة لاعتماديات الخادم والواجهة في `.github/dependabot.yml`.
